# AlertaRS Web — Projeto Integrador IV-B (UCS)

> **Interface Humano-Computador (IHC) e Programação Front-End**  
> *Universidade de Caxias do Sul (UCS) — Curso Superior de Tecnologia em Análise e Desenvolvimento de Sistemas (ADS)*

Plataforma Web com impacto social voltada ao monitoramento hidrometeorológico em tempo real e alerta precoce de inundações para as cidades e bairros do Rio Grande do Sul.
